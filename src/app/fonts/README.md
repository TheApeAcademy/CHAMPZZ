# Self-hosted fonts

Bundled so kids' devices never call Google Fonts and builds never depend on it.
Files come from Fontsource (npm `@fontsource-variable/archivo`, `@fontsource-variable/nunito-sans`,
`@fontsource/mr-dafoe`, v5.3.0), Latin subset.

- Archivo (variable: weight 100 to 900, width 62 to 125), Copyright The Archivo Project Authors
- Nunito Sans (variable: weight 200 to 1000), Copyright The Nunito Sans Project Authors
- Mr Dafoe, Copyright Sudtipos
- Permanent Marker (landing page only), Copyright Font Diner
