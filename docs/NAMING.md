# Champzz naming system (proposal)

Banks asked for everything to be champion themed. This is the proposed vocabulary. Nothing is final until Banks signs off.

## The quiz show

Banks suggested "Who Wants to Be a Champ". The audit (section 7) flagged the quiz as a copy of "Who Wants to Be a Millionaire", and that name keeps the most recognisable part of that brand, its title pattern. For a paid product that is the kind of name that brings a takedown letter, so it is not recommended. The same energy with nothing borrowed:

| Option | Feel |
|---|---|
| **Road to Champ** (recommended) | A journey up five tiers to the title. Works for churches and clubs, reads well on a projector. |
| Champ Climb | Short, punchy, the ladder in two words. |
| The Champ Show | Game-show night, host-led, big screen. |
| Crown Climb | Climb to the crown. |

Proposed format for Road to Champ, original to Champzz:

- **Five tiers, not a money ladder**: Rookie, Rising Star, All-Star, Legend, CHAMP. Two questions per tier, getting harder.
- **Power-ups** instead of lifelines: **Half Time** (removes two wrong answers), **Ask the Squad** (the room votes, the host taps the result), **Coach's Call** (the teacher gives a hint written into the question).
- **Shot Clock** timer.
- No elimination (CCT's best rule, kept): a wrong answer shows the right one and play goes on.
- Teams or solo, relay mode, offline, all as in CCT.
- New look, new sounds, new music. Nothing from the TV show.

## Across the product

| Feature | Champzz name |
|---|---|
| Org's page (the "subreddit") | **Clubhouse** |
| Kids' home world (CCT's Kids Village) | **Champ Town** |
| XP | **Champ Points** |
| Levels | Rookie, Rising Star, All-Star, Legend, Champ (shared with the quiz tiers) |
| Badges | **Trophies** |
| Leaderboard | **Hall of Champs** |
| Daily streak | **Fire Streak** |
| Lessons (CCT's Bible Journey) | **Faith Quest** in faith mode, **Quest** otherwise |
| Avatar that grows | **My Champ** |
| Digital ID and name tag | **Champ Card** |
| Practice mode | **Training Ground** |
| Games section | **The Arena** |
| Seasonal events | **Championship Season** (e.g. the Christmas Cup, the Easter Games) |

## What does not get a hype name

Safeguarding stays calm and plain. CCT's "Ears for You" becomes **Talk to Someone**. A frightened child should never have to decode a brand name to ask for help.
